## Why
An invite the user accepted elsewhere lives in Google Calendar and has no row in
`events`, so no stored identity hint could reach it. It was compared by title,
time and an LLM judgement, and when that declined the same event was proposed as
New again — the user's original report.

Google Calendar returns `iCalUID` on every event, and it is the same UID the
invite carried. That word appeared nowhere in the codebase.
